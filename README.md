# Rhythm Level Generator (Geode, GD 2.2091)

Мод генерирует в редакторе играбельный layout-уровень под любую песню. Биты, сильные доли,
дропы, брейки и длинные ноты определяются анализом аудио (без ИИ), геймплей строится в такт.

## Как пользоваться
1. Открой уровень в редакторе, вверху по центру нажми кнопку **AutoGen**.
2. **Choose Song** открывает родное меню песен GD: поле ID, поиск Newgrounds, Music Library 2.2, NCS.
   Песня скачается сама. Если песня не выбрана, берётся основной трек уровня.
3. Выбери сложность (Easy … Demon), сид (**New**), офсет синхронизации (**−/+**) и опции:
   - **Clear old gen** — удаляет прошлую генерацию: все объекты тех типов, что ставит генератор;
   - **Effects** — включает триггеры.

   Затем нажми **Generate**.

## Как устроена генерация (`src/gen/`)
Во всех режимах подход один: сначала строится путь игрока по музыке, потом вокруг пути ставятся
препятствия. Каждый участок выбирается поиском: пул случайных кандидатов, затем циклы улучшения
победителя отжигом. Оценка — «зрелищность»: разнообразие приёмов, попадание в сильные удары,
отсутствие повторов. Варианты, где физика не может выполнить клик, штрафуются.

- **Cube** (`Cube.cpp`):
  - ритм фраз по схемам AAAB / ABAB / … из реальных онсетов;
  - для каждого такта 24 кандидата и 60 шагов улучшения;
  - прыжки, жёлтые, розовые и красные орбы и пады, dash-орбы на длинных нотах;
  - плато до 4 блоков, сход с края, лестницы, колонны;
  - переход на потолочную плоскость синим орбом или падом (Harder+). Вверх ногами — только
    простые прыжки и пауза после приземления;
  - штраф за приёмы, которые уровень уже часто использовал.
- **Ball / Spider** (`Flip.cpp`):
  - перевороты кликом или гравитационным порталом ровно в бит;
  - рельеф меняется: пока игрок на одной поверхности, другая сдвигается на блок;
  - шипы на «неправильной» поверхности.
- **Wave** (`Corridor.cpp`):
  - поиск по выбору переключений;
  - мини/обычный размер меняется посреди участка там, где волна успевает развернуться;
  - фразы разной ширины, сужения на кик, спам на дропах, гравитационные порталы.
- **Ship** (`Corridor.cpp`):
  - поиск высот ключевых точек;
  - стили «тоннель» и «ворота» (широкий коридор, ворота смыкаются на ударах);
  - прямые узкие пролёты на длинных нотах, смена размера, гравитация.
- **Структура** (`Plan.cpp`):
  - в громких частях режим меняется каждые 2–4 такта, скорость гуляет;
  - зеркало и гравитация на дропах.

**Триггеры** (`Effects.cpp`). Палитра уровня и цвета блоков не меняются.
- Препятствия прячутся за экраном и въезжают на место на восьмую прямо перед игроком
  (снизу, сверху, сбоку, по дуге — у каждой части своя тема). Пройденное рушится вниз и гаснет.
- Камера: отдаление в полётах, удар зумом, тряска и shockwave на дропах, наклоны в пиках,
  radial blur на нарастании.
- Белые вспышки на кик и снейр, хроматика на снейрах, bulge, glitch и pixelate на смене режима,
  инверсия на главном дропе.
- Стены коридоров «дышат», фоновый декор крутится и прыгает в такт.

ID объектов и ключи свойств сверены с таблицами [gmdbuilder](https://github.com/LXtreme/gmdbuilder).

## Сборка
GitHub Actions (`.github/workflows/build.yml`) собирает мод из ветки `v6` Geode SDK (GD 2.2091)
и линкует с бинарниками Geode 5.11.2.

Офлайн-тест анализатора и генератора (без GD), с проверкой коридоров и ловушек:
```bash
python -m ziglang c++ -std=c++20 -O2 -D_USE_MATH_DEFINES test/offline_test.cpp src/Analysis.cpp src/Generator.cpp src/gen/*.cpp -o offline_test.exe
```

## Ограничения
- Физика игрока задана приближённо и с запасом: скорости орбов и падов, гравитация шара,
  импульс синих орбов, хитбоксы. Перед публикацией уровень стоит пройти.
- Шрифты GD не поддерживают кириллицу, поэтому интерфейс мода на английском.
