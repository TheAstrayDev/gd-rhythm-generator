# Rhythm Level Generator (Geode, GD 2.2091, Geode v5.11.2)

Мод генерирует в редакторе играбельный layout-уровень под любую песню: биты, сильные доли,
дропы и брейки определяются анализом аудио (без ИИ), геймплей строится в такт.

## Как пользоваться
1. Открой уровень в редакторе → вверху по центру кнопка **AutoGen**.
2. **Song Library** открывает родное меню песен GD: поиск Newgrounds, Music Library 2.2, NCS.
   Либо введи ID в поле и нажми **Set**. Песня скачается сама. Если ID не задан, берётся
   основной трек уровня.
3. Выбери сложность (Easy … Demon), сид и опции (*Clear level*, *Effects*), затем **Generate**.
4. Если клики ощущаются раньше или позже музыки, поправь *Sync offset (ms)* в настройках мода.

## Что внутри
**Анализ (`src/Analysis.cpp`)**: FMOD декодирует песню, дальше считается STFT и спектральный flux
по полосам. Темп ищется автокорреляцией, биты — DP-трекером Эллиса и глобальной подгонкой сетки
по всей песне с упором на кик. Сильная доля определяется по кику, снейру и скачкам энергии.
Секции песни (calm / mid / high / peak) и дропы выделяются по энергии 4-тактовых фраз.

**Генерация (`src/Generator.cpp`)**, подход «сначала путь игрока»:
- **Cube**: симулируется траектория по кликам на битах, шипы/блоки ставятся только туда, где
  игрок гарантированно проходит с запасом. Есть цепочки жёлтых и розовых орбов над ямой из шипов
  и жёлтые пады на сильные доли.
- **Ship**: коридор по плавной траектории с точками поворота на долях.
- **Wave**: зигзаг с переключением строго на долях, стены из масштабированных блоков.
- **Ball / Spider**: смена гравитации на долях, шипы на «неправильной» поверхности.
- Режим и скорость (порталы 0.5x–4x) выбираются по энергии секции, на дропах — быстрее и жёстче.

**Триггеры**: Color (палитра по секциям), Pulse на каждый бит (сильнее на сильную долю),
Move (препятствия «вылетают» на место в такт, стены коридора «дышат» на дропах), Alpha (пройденное
гаснет), Shake на дропах, Camera Rotate в пиковых секциях. Парные Move-триггеры дают суммарное
смещение ровно 0, поэтому позиции геймплея не зависят от масштаба единиц Move.

## Сборка
- **GitHub Actions**: залей папку в репозиторий. `.github/workflows/build.yml` соберёт `.geode`,
  его нужно положить в `Geometry Dash/geode/mods`.
- **Локально**: Geode SDK v5.11.2 (`GEODE_SDK`), Geode CLI, Visual Studio 2022 и CMake, затем `geode build`.

Офлайн-тест анализатора и генератора (без GD):
```bash
python -m ziglang c++ -std=c++20 -O2 -D_USE_MATH_DEFINES test/offline_test.cpp src/Analysis.cpp src/Generator.cpp -o offline_test.exe
```

## Ограничения
- Физика игрока (высота прыжка, гравитация шара, хитбоксы) задана приближённо и с запасом. Перед
  публикацией уровень стоит пройти: генератор даёт хорошую основу, но не готовый verified-уровень.
- Шрифты GD не поддерживают кириллицу, поэтому интерфейс мода на английском.
